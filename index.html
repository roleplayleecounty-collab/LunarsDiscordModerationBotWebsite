COMMAND LIBRARY

Powerful commands.

Lyra Moderation currently provides a growing collection of moderation, management, utility, staff and developer commands.

🛡️

Moderation

Keep your server under control.

/ban Ban a member
/kick Kick a member
/warn Warn a member
/warnings View member warnings
/timeout Timeout a member
/clear Delete messages
/nick Change a member nickname
/lock Lock a channel
👮

Staff & Management

Configure your moderation team.

/staffrole Configure the staff role
/adminrole Configure the administrator role
/staffsetup Configure staff systems
/logsetup Configure moderation logs
/stickynote Create a sticky message
/rename Rename supported channels
/adduser Add a member to supported systems
/removeuser Remove a member from supported systems
🔧

Utility

Useful commands for members and staff.

/ping Check Lyra's latency
/help View the command help menu
/botinfo View Lyra information
/serverinfo View server information
/whois View member information
/afk Set or remove your AFK status
/avatar View a member's avatar
/userinfo View detailed user information
🔊

Voice & Sounds

Voice utilities and Lyra's sound system.

/joinvc Owner-only voice join command
/playsound Play a sound from Lyra's library
/soundlist View installed sounds
/leavevc Disconnect Lyra from voice
👑

Developer

Restricted controls for Lyra's owner and developers.

/eval Developer evaluation tool
/reload Reload bot commands
/restart Restart Lyra
/setactivity Change Lyra's activity
/setstatus Change Lyra's status
/guilds View bot server statistics
💡

Note: Command availability depends on your server's configuration and the permissions assigned to Lyra's staff and administration roles.
